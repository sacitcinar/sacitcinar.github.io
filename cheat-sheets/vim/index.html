Codex/Vim

Vim

Essential Vim keys for editing, movement, search, saving and working with multiple files.

Replace <…> with your value; […] is optional.

Keys apply in Normal mode unless stated. : starts a command; / between keys separates alternatives.

In examples, → separates successive keystrokes; do not type the arrows.

Modes & inserting

Key / commandDescription
EscReturn to Normal mode.
iInsert before the cursor.
IInsert before the first non-blank character.
aInsert after the cursor.
AInsert at the end of the line.
oOpen a new line below and enter Insert mode.
OOpen a new line above and enter Insert mode.
vStart characterwise Visual selection.
VStart linewise Visual selection.
Ctrl+vStart blockwise Visual selection.

Saving & quitting

Key / commandDescription
:wSave the current file.
:wqSave and close the current window.
:qClose the current window if no changes are pending.
:q!Close the window and discard unsaved changes.
:w <file>Write the buffer to the specified file.

Movement

Key / commandDescription
h / j / k / lMove left / down / up / right.
w / bMove to the next / previous word start.
0 / $Move to the start / end of the line.
gg / GMove to the first / last line.
<line>GJump to a line number.
Ctrl+d / Ctrl+uScroll down / up half a screen.
%Jump to a matching bracket.

Editing & undo

Key / commandDescription
uUndo the last change.
Ctrl+rRedo an undone change.
ddDelete the current line into a register.
dwDelete through the next word start.
yyCopy the current line into a register.
p / PPut register contents after / before the cursor.
xDelete the character under the cursor.
ciwReplace the word under the cursor.
cwChange from the cursor to the word end.
>> / <<Indent / unindent the current line.
.Repeat the last change.

Examples

ExampleDescription
V → j → >Select this line and the next, then indent both.

Search & replace

Key / commandDescription
/<pattern>Search forward.
?<pattern>Search backward.
n / NRepeat the search / reverse its direction.
*Search forward for the word under the cursor.
:nohlsearchClear the current search highlighting.

Examples

ExampleDescription
:%s/old/new/gcReplace matches throughout the file, confirming each.

Files, windows & help

Key / commandDescription
:e <file>Open a file in the current window.
:lsList buffers.
:bn / :bpSwitch to the next / previous buffer.
:split <file>Open a file in a horizontal split.
:vsplit <file>Open a file in a vertical split.
Ctrl+w wMove to the next window.
:help <topic>Open Vim help for a topic.

Examples

ExampleDescription
:vsplit notes.txt → Enter → Ctrl+w wOpen a vertical split, then switch windows.
