HTTP / cURL

HTTP methods, response codes and practical curl options for everyday requests.

Replace <…> with your value; […] is optional.

Options below follow curl <url>. In Windows PowerShell 5.1, use curl.exe to avoid the curl alias.

Examples use POSIX-shell quoting and illustrative example.com URLs.

Everyday requests

Command / optionDescription
curl <url>Request a URL and print the response body.
-IMake a HEAD request and show headers.
-iInclude response headers with the body.
-LFollow HTTP redirects.
-H "<name>: <value>"Add or replace a request header.
-X <method>Set the method; does not supply a request body.

Request data & authentication

Command / optionDescription
-d '<data>'Send a request body; HTTP defaults to POST.
--json '<json>'Send JSON with JSON Content-Type and Accept.
-F '<field>=@<file>'Upload a file as multipart form data.
-u '<user>:<password>'Supply credentials for server authentication.
-H 'Authorization: Bearer <token>'Send a bearer token header.
-G --data-urlencode '<name>=<value>'Send URL-encoded data in the query string.
--data-binary @<file>Send the file body without text conversion.
-b '<name>=<value>'Send cookies; -b <file> reads a cookie file.
-c <file>Save received cookies to a cookie jar file.

Examples

ExampleDescription
curl --json '{"name":"demo"}' https://example.com/apiSend a JSON POST request.
curl -H 'Authorization: Bearer TOKEN' https://example.com/apiSend an example bearer token.
curl -F 'file=@report.pdf' https://example.com/uploadUpload a file as multipart form data.
curl -G --data-urlencode 'q=hello world' https://example.com/searchAdd a URL-encoded query parameter.
curl -b 'session=DEMO' -c cookies.txt https://example.comSend a cookie and save received cookies.

Files & output

Command / optionDescription
-o <file>Save the response body to a local file.
-OUse the filename from the URL path.
-D <file>Save response headers to a file.
-sSHide progress while retaining error messages.
-w '%{http_code}'Print the HTTP status after the transfer.

Examples

ExampleDescription
curl -L -o report.pdf https://example.com/report.pdfFollow redirects and save the response body.

Connections & troubleshooting

Command / optionDescription
-vShow verbose connection and header details.
--connect-timeout <seconds>Limit the connection establishment time.
--max-time <seconds>Limit the total transfer duration.
--fail-with-bodyReturn an error for HTTP 400+ and keep the body.

Examples

ExampleDescription
curl -v --connect-timeout 5 --max-time 20 https://example.comInspect the connection with time limits.

HTTP methods

MethodDescription
GETRetrieve a representation of a resource.
POSTSubmit data for resource-specific processing.
PUTCreate or replace the target resource state.
PATCHApply partial changes to a resource.
DELETERequest removal of the target association.
HEADRetrieve GET-like headers without the body.
OPTIONSRequest supported communication options.

Common response codes

Status codeDescription
200OK — the request succeeded.
201Created — one or more resources were created.
204No Content — success without a response body.
301Moved Permanently — use the new location.
302Found — a temporary redirect.
307Temporary Redirect — preserve the request method.
308Permanent Redirect — preserve the request method.
400Bad Request — the server cannot process the request.
401Unauthorized — authentication credentials are needed.
403Forbidden — the server refuses the request.
404Not Found — the target resource was not found.
429Too Many Requests — a rate limit was exceeded.
500Internal Server Error — an unexpected server failure.
502Bad Gateway — an invalid upstream response.
503Service Unavailable — the server is temporarily unable.
