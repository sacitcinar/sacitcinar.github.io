Codex/PowerShell

PowerShell

Everyday commands for files, object pipelines, processes and Windows administration.

Replace <…> with your value; […] is optional.

Pipelines pass objects. Pipeline commands follow <command> |; Windows-only cmdlets require Windows.

Files & navigation

CommandDescription
Get-ChildItem <path>List files and directories.
-RecurseInclude child directories recursively.
-ForceInclude hidden and system items when supported.
Set-Location <dir>Change the current location.
Get-LocationShow the current location.
Test-Path <path>Check whether a path exists.
Get-Content <file>Read file contents.
Get-Content <file> -Tail <count> -WaitFollow appended lines in a text file.
Set-Content <file> -Value <text>Write text, replacing existing file contents.
Add-Content <file> -Value <text>Append text to a file.
Select-String -Path <file> -Pattern <regex>Find text matching a regular expression.
Copy-Item <source> <destination>Copy an item.
Move-Item <source> <destination>Move or rename an item.
New-Item <path> -ItemType FileCreate an empty file.
Remove-Item <path>Remove the selected item.
Get-FileHash <file>Calculate a file’s SHA-256 hash by default.

Examples

ExampleDescription
Get-ChildItem . -Filter *.log -RecurseFind .log files in the current directory tree.

Pipelines & objects

CommandDescription
<command> | Get-MemberInspect object properties and methods.
Where-Object { <condition> }Filter incoming objects.
Select-Object <properties>Choose output properties.
Sort-Object <property>Sort incoming objects by a property.
ForEach-Object { <action> }Process each incoming object.
Measure-ObjectCount incoming objects.

Examples

ExampleDescription
Get-Process | Where-Object { $_.CPU -gt 60 }Select processes using over 60 CPU seconds.
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5Show five processes with the highest CPU time.

Processes & services

CommandDescription
Get-ProcessList running processes.
Get-Process -Id <pid>Inspect a process by ID.
Get-Service [<name>]List Windows services or inspect one.
Stop-Process -Id <pid>Stop the selected process.
Restart-Service <name>Restart a Windows service.

Logs & networking

CommandDescription
Get-WinEvent -LogName <log>Read events from a Windows log.
Get-WinEvent -FilterHashtable @{LogName='System'; Id=6005}Read System events with event ID 6005 on Windows.
Test-Connection <host>Send ICMP echo requests.
Test-NetConnection <host> -Port <port>Test a TCP connection on Windows.
Get-NetTCPConnectionList TCP connections on Windows.

Examples

ExampleDescription
Get-WinEvent -FilterHashtable @{LogName='System'; Level=2}Read error-level System events on Windows.

Data & requests

CommandDescription
Import-Csv <file>Read CSV rows as objects.
Export-Csv <file> -NoTypeInformationSave incoming objects as CSV.
ConvertFrom-JsonParse incoming JSON text into objects.
ConvertTo-JsonSerialize incoming objects as JSON.
Invoke-RestMethod -Uri <url>Request an endpoint and parse its response.

Examples

ExampleDescription
$rows = Get-Process | Select-Object Name, Id$rows | Export-Csv processes.csv -NoTypeInformationExport process names and IDs to a CSV file.
Get-Content config.json -Raw | ConvertFrom-JsonRead a JSON file into PowerShell objects.

Help & scripting

CommandDescription
Get-Help <command> -ExamplesShow command examples.
Get-Command <pattern>Find available commands.
$name = <value>Assign a variable.
$env:<name>Read an environment variable.
