Hosts & ports

Filter / expressionDescription
ip.addr == <ip>Match either IPv4 endpoint.
tcp.port == <port>Match either TCP port.
udp.port == <port>Match either UDP port.
ip.src == <ip>Match the source IPv4 address.
ip.dst == <ip>Match the destination IPv4 address.
tcp.stream == <id>Isolate one TCP conversation.
ipv6.addr == <ipv6>Match either IPv6 endpoint.
eth.addr == <mac>Match either Ethernet address.

Examples

ExampleDescription
ip.addr == 192.168.1.10 && tcp.port == 443Show TCP port 443 traffic involving this host.

Common protocols

Filter / expressionDescription
tcpShow packets decoded as TCP.
udpShow packets decoded as UDP.
dnsShow decoded DNS traffic.
httpShow decoded HTTP traffic.
tlsShow decoded TLS traffic.
icmpShow IPv4 ICMP traffic.
arpShow address-resolution traffic.

Filter operators

Filter / expressionDescription
<filter1> && <filter2>Require both conditions.
<filter1> || <filter2>Accept either condition.
!(<filter>)Exclude matching packets.
(<filter>)Group conditions explicitly.
http.host contains "<text>"Find text within an HTTP Host field.
http.host matches "<regex>"Match an HTTP Host with a regular expression.

Examples

ExampleDescription
(dns || http) && !(ip.addr == 192.168.1.10)Show DNS or HTTP, excluding this host.

HTTP, DNS & TLS

HTTP fields require decoded HTTP traffic; encrypted HTTPS needs decryption.

Filter / expressionDescription
http.requestShow HTTP requests.
http.request.method == "<method>"Select a request method, such as GET or POST.
http.response.code == <code>Match an HTTP response status.
http.host == "<domain>"Match the HTTP Host field.
http.request.uri contains "<text>"Find text in a request URI.
dns.qry.name == "<domain>"Match a DNS query name.
dns.flags.response == 0Show DNS queries.
dns.flags.rcode != 0Show DNS responses with a nonzero result code.
tls.handshake.type == 1Show visible TLS Client Hello messages.
tls.handshake.type == 2Show visible TLS Server Hello messages.

Examples

ExampleDescription
dns.qry.name == "example.com"Match DNS messages with this query name.
http.response.code >= 400 && http.response.code < 600Show decoded HTTP client and server errors.

TCP analysis

Filter / expressionDescription
tcp.flags.syn == 1Show segments with the SYN flag set.
tcp.flags.reset == 1Show connection resets.
tcp.flags.fin == 1Show segments with the FIN flag set.
tcp.analysis.retransmissionShow suspected TCP retransmissions.
tcp.analysis.fast_retransmissionShow suspected fast retransmissions.
tcp.analysis.duplicate_ackShow duplicate acknowledgments.
tcp.analysis.zero_windowShow advertised zero receive windows.

Examples

ExampleDescription
tcp.flags.syn == 1 && tcp.flags.ack == 0Show initial SYN segments, excluding SYN/ACK.

Capture filters

Set these before capture; the filter tables above use display syntax.

Filter / expressionDescription
host <ip>Capture traffic involving a host.
port <port>Capture TCP or UDP traffic on a port.
tcp port <port>Capture TCP traffic on a port.
udp port <port>Capture UDP traffic on a port.
net <network/CIDR>Capture traffic involving a network.
src host <ip>Capture packets from a host.
dst host <ip>Capture packets sent to a host.
not port <port>Exclude traffic matching a port.

Examples

ExampleDescription
host 192.168.1.10 and tcp port 443Capture this host’s TCP port 443 traffic.
