Files & directories

Command / optionDescription
ls [<dir>]List directory contents.
-lLong listing format
-aInclude hidden entries
-hHuman-readable sizes with -l
-RList subdirectories recursively
-tNewest modification time first
cd <dir>Change the working directory.
pwdPrint the current working directory.
cp <source> <destination>Copy files; directories require -r or -a.
-aCopy recursively and preserve file attributes
-rCopy directories recursively.
mv <source> <destination>Move or rename files and directories.
mkdir <dir>Create directories.
-pCreate missing parent directories
rm <file>Remove files; use -r for directory contents.
-iAsk before removing a file
-rRemove directories and their contents recursively.
touch <file>Create an empty file or update its timestamps.
find <dir>Find files and directories.
-type fMatch regular files
-name "<pattern>"Match filenames against a pattern
tree [<dir>]Display a directory tree.
-aInclude hidden files.
-L <depth>Limit the displayed directory depth.
-dShow directories only.
du <dir>Show file and directory disk usage.
-sShow a total for each argument
-hHuman-readable sizes
df [<path>]Show filesystem space usage.
-hHuman-readable sizes
stat <file>Show file metadata.
which <command>Find an executable in the shell search path.
-aShow all matching executables in PATH.
locate <pattern>Find paths using the filename database.
-iIgnore case.
-eOnly include paths that currently exist.
rmdir <dir>Remove an empty directory.

Examples

ExampleDescription
find . -type f -name '*.log'Find .log files beneath the current directory.
cp -r reports reports-backupCopy a directory and its contents.

Text & editing

Command / optionDescription
cat <file>Print file contents.
grep <pattern> <file>Find lines matching a pattern.
-RSearch directories recursively
-nShow line numbers
-iIgnore case
less <file>Read text one page at a time.
qQuit the viewer
tail <file>Show the end of a file.
-fFollow newly appended lines
head <file>Show the beginning of a file.
-n <count>Print the first <count> lines
nano <file>Edit a file in the terminal.
sort <file>Sort lines of text.
-nSort numerically.
-rReverse the sort order.
-uOutput unique lines.
wc <file>Count lines, words and bytes.
-lCount lines.
-wCount words.
-cCount bytes.
cut -f <fields> <file>Extract selected fields; tabs delimit by default.
-d <delimiter>Set the field delimiter
-f <fields>Select fields to extract
awk '<program>' <file>Process text by patterns and fields.
sed '<script>' <file>Filter and transform text.
tr '<set1>' '<set2>'Translate characters from standard input.
-d <set>Delete characters from the specified set.
-s <set>Squeeze repeated characters from the set.
column [<file>]Format input into columns.
-tCreate a table from input fields.
-s <separator>Set the input field separator.

Examples

ExampleDescription
grep -n 'error' app.logFind error lines and show their line numbers.
cut -d ':' -f 1 /etc/passwdPrint account names from the first field.
awk '{print $1}' access.logPrint the first whitespace-separated field.
sed 's/old/new/g' notes.txtPrint replaced text; leave the file unchanged.

Permissions & accounts

Command / optionDescription
sudo <command>Run commands with permitted privileges.
-lList permitted commands
whoamiPrint the effective username.
idShow user and group IDs.
chmod <mode> <file>Change file permissions.
640Owner read/write; group read; others no access
+xAdd execute permission
chown <user>:<group> <file>Change file ownership.
passwd [<user>]Change an account password.
usermod <options> <user>Modify an existing user account.
-aG <group>Append the user to a supplementary group.
-LLock the account password.
useradd <user>Create a user account.
-mCreate the home directory.
-s <shell>Set the login shell.
userdel <user>Delete a user account.
-rAlso remove the home directory and mail spool.
getent <database>Query configured account databases.
lastShow login history.
-aShow the hostname in the last column
addgroup <group>Create a group on Debian-based systems.
delgroup <group>Delete a group on Debian-based systems.

Examples

ExampleDescription
chmod 640 report.txtOwner: read/write; group: read; others: none.

System & terminal

Command / optionDescription
unameShow kernel and system information.
-aShow all available system information
hostname [<name>]Show or set the system hostname.
uptimeShow system uptime and load averages.
freeShow memory usage.
-hHuman-readable sizes
lsblkList block devices.
-fShow filesystem information
dateShow the current date and time.
-uUse UTC.
clearClear the terminal display.
cal [<month> <year>]Display a calendar.
man <command>Open a command’s manual page.
<command> --helpShow help for commands that support --help.

Processes & services

Command / optionDescription
psShow running processes.
auxList processes for all users, including those without a terminal
systemctl <action> <service>Inspect and manage systemd services.
statusShow service state and recent log entries.
startStart the service now.
stopStop the service now.
restartStop and start the service.
enableEnable startup at boot; does not start it now.
journalctlRead systemd journal entries.
-u <service>Filter by service
--since <time>Filter by start time
-bShow the current boot
-p <priority>Filter by message priority
--since todayShow today’s entries
topMonitor processes and resource usage.
kill <pid>Send a signal to a process.
-TERMRequest graceful termination
pgrep <pattern>Find processes by name or command line.
-aShow the full command line
-fMatch the full command line
htopInteractively monitor processes and resource use.

Examples

ExampleDescription
journalctl -u ssh --since todayRead today’s entries for the ssh service.

Networking & remote access

Command / optionDescription
ip <object> [<action>]Show and manage network interfaces and routes.
-br addrShow interface addresses briefly
routeShow the routing table
ping <ip>Test network reachability with ICMP.
-c <count>Send <count> echo requests
ssInspect network sockets.
-tTCP sockets
-uUDP sockets
-lListening sockets
-nNumeric addresses and ports
ssh <user>@<host>Open an encrypted remote shell.
-p <port>Connect to the specified port.
-i <keyfile>Use the specified private key.
curl <url>Transfer data and inspect HTTP responses.
-IMake a HEAD request and show headers.
dig <domain>Query DNS records.
wget <url>Download a file from a URL.
-O <file>Save output using the specified filename.
-cResume a partial download.
tcpdump [<filter>]Inspect network traffic on authorized interfaces.
-i <interface>Select a capture interface
-nnDisable host and port name resolution
port <port>Filter traffic by port
ifconfig [<interface>]Legacy interface tool; prefer ip on modern Linux.
-aShow all interfaces, including inactive ones.
netstatLegacy socket tool; prefer ss on modern Linux.
-tShow TCP sockets.
-uShow UDP sockets.
-lShow listening sockets.
-nShow numeric addresses and ports.
-pShow associated processes when permitted.

Examples

ExampleDescription
ss -tulnList listening TCP and UDP sockets numerically.

Archives & compression

Command / optionDescription
tar <options>Create or extract tar archives.
-cCreate an archive.
-xExtract an archive.
-tList archive contents.
-f <archive>Select the archive filename.
-zUse gzip compression.
-C <dir>Change directory before processing files.
gzip <file>Compress a file using gzip.
-dDecompress the file.
-kKeep the input file.
zip <archive.zip> <file>Create or update a ZIP archive.
-r <dir>Include a directory recursively.
unzip <archive.zip>Extract a ZIP archive.
-lList archive contents.
-d <dir>Extract into the specified directory.

Examples

ExampleDescription
tar -czf <archive.tar.gz> <dir>Create a gzip-compressed archive.
tar -xzf <archive.tar.gz>Extract a gzip-compressed archive.

Package management

Command / optionDescription
apt <action>Manage packages on Debian and Ubuntu.
updateRefresh package indexes
upgradeUpgrade installed packages without removing packages.
list --upgradableList packages with updates available
install <package>Install a package.
remove <package>Remove a package; retain its configuration files.
dpkg -lList installed packages and package status.
dnf <action>Manage packages on Fedora and RHEL-based systems.
check-updateCheck for available package updates
install <package>Install a package.
remove <package>Remove a package.
pacman <options>Manage packages on Arch-based systems.
-SyuRefresh package databases and upgrade the system
-S <package>Install a package from configured repositories.
-R <package>Remove a package.

Examples

ExampleDescription
sudo apt install curlInstall curl on Debian or Ubuntu.
sudo apt updatesudo apt upgradeRefresh package lists, then upgrade packages.
