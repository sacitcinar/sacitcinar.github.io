GITHUBPYTHONCLI

URL Reputation Checker

A CLI tool combining eight intelligence sources, plus optional OpenPhish support, with domain context and URL heuristics. Delivers a unified report with a risk score, verdict and coverage summary.

View on GitHub ↗
  1. 🔗 URL / defanged URL
  2. Refang & normalize
  3. 🌐 Intel + heuristics
  4. 📊 Risk score
  5. 🛡️ Verdict

One view of URL reputation

The checker brings existing threat records, domain and IP context, and URL structure into a single report. It does not directly visit the submitted website or submit a new scan.

From URL to assessment

  1. Prepare the input.

    Normalize the URL and handle defanged input before extracting its domain and structural indicators.

  2. Collect the evidence.

    Combine existing intelligence records with DNS, RDAP, domain age, ASN and geolocation context, then inspect impersonation and URL heuristics.

  3. Explain the outcome.

    Finish with a 0–100 risk score, verdict and coverage summary. Missing keys or failed requests are shown as unavailable, not reported as clean.

Intelligence sources

Eight intelligence integrations are available, with optional support for a user-provided OpenPhish list. Domain and IP context is included separately.

  • VirusTotal
  • Google Safe Browsing
  • URLhaus
  • PhishTank
  • CERT Polska
  • Phishing.Database
  • urlscan.io
  • AbuseIPDB
  • OpenPhish

What it includes

  • Single-URL analysis and TXT/CSV batch input.
  • Typosquatting, brand impersonation and Unicode/Punycode heuristics.
  • JSON or Markdown reports, selectable providers and automation-friendly exit codes.
  • Python 3.10+ with no external Python packages required.

Run it locally

Configure the API keys you have in your local .env file. Providers without required credentials are marked as skipped or unavailable.

›_ Usage example
python3 app.py 'https://example.com/login'

# Save a JSON report
python3 app.py 'https://example.com/login' -o report.json

These screenshots come from the repository’s EICAR example. EICAR is a harmless anti-malware test file; the displayed verdict reflects the intelligence records at the time of that example.

Reading the result

The risk score is not a probability, and a missing match does not prove safety. Review the findings and coverage together. Third-party lookups may receive the submitted URL; report redaction affects displayed and saved output rather than provider requests.
