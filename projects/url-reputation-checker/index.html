URL Reputation Checker

A command-line tool for checking suspicious URLs. It looks up existing threat records, gathers domain and IP information, and checks the address for signs of impersonation. The tool performs lookups without opening the target site or submitting a new scan.

View on GitHub ↗

How it works

  1. Normalize the URL, including defanged input such as hxxps[:]//example[.]com.
  2. Look up existing reputation records and gather DNS, RDAP and IP information.
  3. Check the URL for lookalike domains, brand impersonation and other suspicious patterns.
  4. Report a risk score from 0 to 100, a verdict and the coverage of the reputation checks.

Run it locally

Run the commands from the project folder with Python 3.10 or newer. Add any provider API keys you have to a local .env file. Sources that require a missing key are marked as skipped or unavailable.

›_ Usage example
python3 app.py 'https://example.com/login'
python3 app.py 'hxxps[:]//example[.]com/login' -o report.json
python3 app.py urls.csv

For batch checks, use a TXT file with one URL per line or a CSV with a url column. Use --offline to check an address against local feeds and URL rules without making network requests.

Reading the report

The risk score reflects the evidence the tool found. Coverage shows how many reputation sources supplied usable results. A low score with limited coverage calls for further checking. UNKNOWN means there wasn’t enough evidence for a verdict of LIKELY SAFE.
