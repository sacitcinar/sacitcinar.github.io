GITHUBPYTHONCLI

Phishing Email Detector

A lightweight, offline CLI tool that analyzes .eml files using machine learning and technical email inspection. Combines text classification with header, link and domain analysis.

Local email triage, with context

The tool brings text classification and technical message inspection into one local workflow. It reads a saved email rather than requiring access to an inbox, so the message can be examined without sending its contents to a remote service.

From message to assessment

  1. Read the message.

    Parse the .eml structure, headers, and plain-text or HTML content.

  2. Classify the text.

    Combine word-level and character-level TF-IDF features with logistic regression to estimate phishing likelihood.

  3. Add technical context.

    Inspect sender and Reply-To domains, linked domains, HTML link targets and other message warnings alongside the model prediction.

What it includes

  • Offline analysis of native .eml files.
  • A lightweight inference package using Python’s standard library; no ML framework installation is needed.
  • A terminal summary and structured JSON output.
  • Separate model predictions, technical findings and warnings for review.

Run it locally

With Python 3 installed, run these commands from the directory containing app.py and model.json.gz.

›_ Usage example
python3 app.py example.eml

# Export structured output
python3 app.py example.eml --json

Reading the result

The final assessment may be PHISHING, LEGITIMATE, REVIEW or UNCERTAIN. The classification threshold is 0.50, but the model estimate is an investigation signal rather than proof.

Attachment contents, images and QR codes are not analyzed. The tool does not visit linked sites, perform live URL reputation checks or independently validate SPF, DKIM and DMARC through DNS.
