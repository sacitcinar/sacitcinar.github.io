Phishing Email Detector

A lightweight command-line tool for investigating suspicious emails saved as .eml files. The analysis runs entirely offline, so the message stays on your computer.

View on GitHub ↗

How it works

  1. Read the subject, headers and body from the .eml file.
  2. Prepare the text using the same steps as during training.
  3. Score the message with word- and character-level TF-IDF features and logistic regression.
  4. Check the sender and Reply-To domains and inspect links in the email.
  5. Report the model prediction, technical findings and final assessment separately.

Run it locally

Open a terminal in the folder containing app.py and model.json.gz. Run the first command for a terminal summary or the second for JSON output.

›_ Usage example
python3 app.py example.eml
python3 app.py example.eml --json

On Windows, use python if that’s how Python is installed.

Email datasets

  • Jose Nazario Phishing Corpus for phishing emails.
  • Apache SpamAssassin Public Corpus for legitimate emails, including the easy_ham collection.
  • CEAS for additional labelled email samples used during development.

Reading the result

The model classifies messages scoring 0.50 or higher as PHISHING. A strong technical finding can trigger REVIEW while the model score stays the same. When the available text or evidence is too limited, the final assessment can be UNCERTAIN.

Attachment contents, images, QR codes, live URL reputation lookups and independent SPF, DKIM or DMARC verification are outside the scope of the analysis.
