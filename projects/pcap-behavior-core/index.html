PCAP Behavior Core

A command-line tool for investigating recorded network traffic offline. It looks for behavior such as TCP scans and recurring connections, then produces an interactive HTML report and structured JSON. Packet references let you trace findings back to the original capture.

View on GitHub ↗

How it works

  1. Decode the packets, group related traffic into flows and pair DNS queries with their replies.
  2. Look for TCP sweeps across hosts or ports, recurring connections, long-lived flows and clusters of NXDOMAIN replies.
  3. Report each finding with its endpoints, time window and supporting evidence. Use the packet references to check it against the capture.

Run it locally

Clone and install the tool with Git and Python 3.10 or newer.

›_ Usage example
git clone https://github.com/sacitcinar/pcap-behavior-core.git
cd pcap-behavior-core
python -m pip install .
python -m pcapcore capture.pcap

The command writes JSON and HTML reports by default. Open the HTML file in a browser to explore it offline. To choose a different output name, run python -m pcapcore capture.pcap -o analysis.json.

Reading the report

Start with the overview to see which hosts and services appear in the capture. Then open Findings to inspect a specific behavior and follow its evidence back to the packets. For example, a periodic connection might come from a scheduled job. Its timing gives you a lead to investigate.

Limits of the analysis

Convert PCAPNG files to classic PCAP before running the tool. The current version covers selected network behaviors and leaves HTTP requests, TLS handshakes and DNS over TCP outside its analysis. It also lacks general TCP stream and IP fragment reassembly. Flows and DNS events stay in memory, so large captures can require more RAM.
