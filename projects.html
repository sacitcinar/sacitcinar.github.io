Network forensics · Behavioral Analysis

PCAP Behavior Core

A Python command-line tool for investigating recorded network traffic. It reads a PCAP file and traces each finding back to the capture.

  • Looks for TCP scanning patterns and connections that repeat at regular intervals.
  • Matches DNS queries with their responses and flags clusters of NXDOMAIN replies.
  • Writes a JSON report and a standalone HTML report with packet references.

Threat intelligence · URL analysis

URL Reputation Checker

A command-line tool for checking a suspicious URL. It collects existing reputation records and checks the address itself for signs of impersonation.

  • Accepts defanged URLs and can read a batch from a TXT or CSV file.
  • Checks eight intelligence sources and adds DNS, domain age and URL findings.
  • Reports a risk score and verdict, with coverage that shows which checks ran.

Email security · ML

Phishing Email Detector

A Python command-line tool for investigating suspicious emails. Give it a saved .eml file and it analyzes the message locally.

  • Uses TF-IDF and logistic regression to estimate whether the message text looks like phishing.
  • Checks sender and Reply-To domains and flags links whose displayed address differs from their destination.
  • Reports the model prediction and technical findings separately in a terminal summary or JSON.
  • Python
  • CLI
  • TF-IDF
  • Logistic regression
