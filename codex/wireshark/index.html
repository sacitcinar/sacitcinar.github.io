Hosts & ports

Filter / expression Description
ip.addr == <ip> Match either IPv4 endpoint.
ip.src == <ip> Match the source IPv4 address.
ip.dst == <ip> Match the destination IPv4 address.
tcp.port == <port> Match either TCP port.
udp.port == <port> Match either UDP port.
tcp.srcport == <port> Match a TCP source port.
tcp.dstport == <port> Match a TCP destination port.
udp.srcport == <port> Match a UDP source port.
udp.dstport == <port> Match a UDP destination port.
tcp.stream == <id> Isolate one TCP conversation.
udp.stream == <id> Isolate one UDP conversation.
ip.addr == <network/CIDR> Match IPv4 traffic involving a subnet.
ipv6.addr == <ipv6> Match either IPv6 endpoint.
eth.addr == <mac> Match either Ethernet address.
frame.number == <N> Select a frame by its capture number.
frame.time_relative > <seconds> Select frames after a relative capture time.

Examples

ip.addr == 192.168.1.10 && tcp.port == 443
Show TCP port 443 traffic involving this host.
ip.addr == 192.0.2.0/24 && tcp.dstport == 443
Show traffic involving a subnet and TCP destination 443.

Common protocols

Filter / expression Description
tcp Show packets decoded as TCP.
udp Show packets decoded as UDP.
dns Show decoded DNS traffic.
http Show decoded HTTP traffic.
tls Show decoded TLS traffic.
icmp Show IPv4 ICMP traffic.
arp Show address-resolution traffic.
icmpv6 Show IPv6 ICMP traffic.
dhcp Show decoded DHCPv4 traffic.
dhcpv6 Show decoded DHCPv6 traffic.

Filter operators

Filter / expression Description
<filter1> && <filter2> Require both conditions.
<filter1> || <filter2> Accept either condition.
!(<filter>) Exclude matching packets.
(<filter>) Group conditions explicitly.
http.host contains "<text>" Find text within an HTTP Host field.
http.host matches "<regex>" Match an HTTP Host with a regular expression.

Examples

(dns || http) && !(ip.addr == 192.168.1.10)
Show DNS or HTTP, excluding this host.

HTTP, DNS & TLS

HTTP fields require decoded HTTP traffic; encrypted HTTPS needs decryption.

Filter / expression Description
http.request Show HTTP requests.
http.request.method == "<method>" Select a request method, such as GET or POST.
http.response.code == <code> Match an HTTP response status.
http.host == "<domain>" Match the HTTP Host field.
http.request.uri contains "<text>" Find text in a request URI.
http.user_agent contains "<text>" Find text in a visible HTTP User-Agent.
http.cookie Show packets containing an HTTP Cookie field.
http.authorization Show packets containing HTTP authorization data.
dns.qry.name == "<domain>" Match a DNS query name.
dns.flags.response == 0 Show DNS queries.
dns.flags.rcode != 0 Show DNS responses with a nonzero result code.
dns.a == <ip> Find DNS A answers containing an IPv4 address.
tls.handshake.extensions_server_name == "<domain>" Match a visible TLS server name.
tls.handshake.type == 1 Show visible TLS Client Hello messages.
tls.handshake.type == 2 Show visible TLS Server Hello messages.

Examples

dns.qry.name == "example.com"
Match DNS messages with this query name.
http.response.code >= 400 && http.response.code < 600
Show decoded HTTP client and server errors.

TCP analysis

Filter / expression Description
tcp.flags.syn == 1 Show segments with the SYN flag set.
tcp.flags.reset == 1 Show connection resets.
tcp.flags.fin == 1 Show segments with the FIN flag set.
tcp.analysis.retransmission Show suspected TCP retransmissions.
tcp.analysis.fast_retransmission Show suspected fast retransmissions.
tcp.analysis.duplicate_ack Show duplicate acknowledgments.
tcp.analysis.zero_window Show advertised zero receive windows.
tcp.len > 0 Show TCP segments carrying payload bytes.
tcp.analysis.lost_segment Show suspected missing TCP segments.
tcp.analysis.out_of_order Show suspected out-of-order TCP segments.

Examples

tcp.flags.syn == 1 && tcp.flags.ack == 0
Show initial SYN segments, excluding SYN/ACK.

Capture filters

Set these before capture; the filter tables above use display syntax.

Filter / expression Description
host <ip> Capture traffic involving a host.
port <port> Capture TCP or UDP traffic on a port.
tcp port <port> Capture TCP traffic on a port.
udp port <port> Capture UDP traffic on a port.
net <network/CIDR> Capture traffic involving a network.
src host <ip> Capture packets from a host.
dst host <ip> Capture packets sent to a host.
not port <port> Exclude traffic matching a port.

Examples

host 192.168.1.10 and tcp port 443
Capture this host’s TCP port 443 traffic.

Common actions

Action / menu Description
Analyze → Follow → TCP Stream Reassemble and inspect the selected TCP conversation.
Statistics → Conversations Compare traffic between pairs of endpoints.
Statistics → Endpoints List hosts and their traffic totals.
Statistics → Protocol Hierarchy Review the capture’s protocol breakdown.
File → Export Objects → <protocol> Save objects supported by the selected protocol.
Analyze → Expert Information Review protocol warnings and analysis messages.
Analyze → Decode As Choose a protocol dissector for selected traffic.
Statistics → I/O Graphs Graph traffic volume and filtered packet rates.
