Search & filtering

Use parentheses: search evaluates OR before AND; where and eval evaluate AND before OR.

SPL query Description
index=<index> <term> Search an index for matching events.
index=<index> sourcetype=<type> Restrict events to a source type.
<field>="<value>" Match a field value in the base search.
earliest=-24h latest=now Limit the base search to the last 24 hours.
| search <condition> Filter pipeline results with search syntax.
| where <expression> Filter results using an eval expression.
<a> AND <b> Require both search conditions.
<a> OR <b> Match either search condition.
NOT (<condition>) Exclude events matching a grouped search condition.
(<a> OR <b>) AND <c> Group Boolean conditions explicitly.
<field> IN ("<a>","<b>") Search for one of several field values.
<field>=* Search for events where a field has a value.
| where isnull(<field>) Keep results where a field is null or missing.
| where isnotnull(<field>) Keep results where a field is not null.
| where like(<field>,"<pattern>") Match text using % and _ wildcards.
| where match(<field>,"<regex>") Keep results matching a regular expression.

Examples

index=web status=404 earliest=-24h
Find 404 events in an example web index.

Fields & result order

SPL query Description
| table <fields> Display selected fields in the given order.
| fields <fields> Retain only selected fields.
| sort - <field> Sort descending; defaults to at most 10,000 rows.
| head <count> Keep the first results.
| dedup <field> Keep the first result per value in the current order.
| fields - <field> Remove a field from results.
| sort 0 - <field> Sort all results without the default 10,000-row limit.

Counts & summaries

SPL query Description
| stats count by <field> Return one count per group; omit other event fields.
| stats dc(<field>) Count distinct field values.
| stats sum(<field>) Sum numeric values.
| stats avg(<field>) by <group> Calculate a mean for each group.
| stats min(<field>) max(<field>) Return the minimum and maximum values.
| stats values(<field>) Collect distinct values into a multivalue field.
| stats list(<field>) Collect values in event order; default limit is 100.
| stats latest(<field>) Return a value from the latest event by _time.
| stats earliest(<field>) Return a value from the earliest event by _time.
| top <field> Show the ten most frequent values.
| eventstats count by <field> Add group counts while retaining events.
| streamstats count by <field> Add a running count in the current event order.
| chart count over <field> by <group> Build a two-dimensional count table.
| tstats count WHERE index=<index> BY host Count using indexed fields rather than raw events.

Examples

index=<index> earliest=-24h | stats count by host
Count events per host over the last 24 hours.
| tstats count WHERE index=main BY host
Count indexed events per host in the main index.

Time-based analysis

SPL query Description
| timechart span=1h count Count events in hourly buckets.
| timechart span=1h count by <field> Split hourly counts by field value.
| bin _time span=5m Round event times into five-minute buckets.
| timechart limit=0 useother=f count by <field> Keep every split-by series without an OTHER series.

Examples

index=web earliest=-24h | timechart span=1h count
Count events in hourly buckets.

Calculated fields

SPL query Description
| eval <field>=<expression> Create or update a field.
| eval label=if(<condition>,"yes","no") Assign a value based on a condition.
| eval label=case(<test>,<value>,true(),"other") Choose the value for the first true condition.
| eval value=coalesce(<a>,<b>) Use the first non-null value.
| rename <old> AS <new> Rename a result field.
| fillnull value="unknown" <field> Fill null values in an existing field.
| eval internal=if(cidrmatch("<CIDR>",<ip>),1,0) Set 1 for an IP inside the subnet, otherwise 0.
| eval epoch=strptime(<field>,"<format>") Parse a timestamp into epoch seconds.
| eval label=strftime(_time,"<format>") Format epoch seconds as a timestamp.
| eval n=mvcount(<field>) Count entries in a multivalue field.
| eval first=mvindex(<field>,0) Get the first multivalue entry.
| eval items=split(<field>,"<delimiter>") Split text into a multivalue field.
| eval text=mvjoin(<field>,"<delimiter>") Join multivalue entries into text.

Examples

index=web | eval result=if(status>=400,"error","ok")
Classify events using an example status field.
index=<index> | eval scope=if(cidrmatch("10.0.0.0/8",src_ip),"internal","other")
Classify source IPs against an example private subnet.

Extraction & enrichment

SPL query Description
| rex field=<field> "<regex>" Extract fields using named regex groups.
| regex <field>="<regex>" Retain results matching a regex.
| spath Extract fields from structured JSON or XML.
| lookup <table> <key> Enrich results using a configured lookup.
| mvexpand <field> Create a result for each multivalue entry.
| inputlookup <table> Start results from a lookup table.
| rex max_match=0 "(?<name>pattern)" Extract all regex matches into a multivalue field.

Examples

index=web | rex field=_raw "user=(?<user>\S+)"
Extract a user field from user= followed by non-space text.
