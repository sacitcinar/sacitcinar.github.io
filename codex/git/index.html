Git

Daily Git commands for reviewing changes, committing, branching and synchronizing repositories.

Daily workflow

Command Description
git status Review changed and staged files.
git diff Show unstaged changes.
git add <path> Stage changes for a path.
git add -A Stage additions, modifications and deletions repository-wide.
git add -p Select individual changes to stage.
git add -u Stage changes and deletions to tracked files only.
git diff --staged Review the next commit’s changes.
git commit -m "<message>" Commit the staged changes.
git commit --amend Replace the latest commit with updated content or message.
git diff --stat Summarize changed files and line counts.
git diff --name-only List changed file paths.

Examples

git add notes.txt git diff --staged git commit -m "Update notes"
Stage a file, review it and create a commit.
git add -A git diff --staged
Stage all changes, then review exactly what will be committed.

Branches & integration

Command Description
git branch List local branches.
git switch <branch> Switch to an existing branch.
git switch -c <branch> Create and switch to a branch.
git merge <branch> Merge another branch into the current branch.
git merge --abort Abandon an in-progress merge.
git branch -a List local and remote-tracking branches.
git branch -m <name> Rename the current branch.
git branch -d <branch> Delete a branch when Git considers it merged.
git rebase <branch> Replay current-branch commits onto another base.
git rebase --continue Continue a rebase after resolving conflicts.
git rebase --abort Abort a rebase and restore its starting state.
git cherry-pick <commit> Apply changes from a specific commit.

Examples

git switch -c feature/docs git add README.md git commit -m "Update documentation"
Create a branch and commit a documentation change.

Remotes & synchronization

Force-with-lease rewrites history; background fetches can weaken its default expected-ref check.

Command Description
git pull --ff-only Update only if a fast-forward is possible.
git push Send commits to the configured upstream.
git fetch <remote> Download remote refs without merging.
git push -u <remote> <branch> Push and set the upstream branch.
git remote -v Show configured remote URLs.
git fetch --prune Fetch and remove stale remote-tracking references.
git remote set-url <remote> <url> Change a remote repository URL.
git push --force-with-lease Rewrite a remote ref only if its expected value matches.

History & inspection

Command Description
git log --oneline Show a compact commit history.
git log --graph --oneline --all View the commit graph across refs.
git show <commit> Inspect a commit and its changes.
git diff <commit1> <commit2> Compare two commits.
git blame <file> Show the last change for each line.
git reflog Inspect recent local movements of HEAD and other refs.
git log -p -- <file> Show commits and patches affecting a file.
git tag <name> Create a lightweight tag at the current commit.

Undo & temporary work

Command Description
git restore --staged <path> Unstage changes while keeping working files.
git restore <path> Discard unstaged changes for the selected path.
git revert <commit> Create a new commit reversing a commit.
git stash push -m "<message>" Set aside tracked-file changes temporarily.
git stash list List saved stashes.
git stash pop Apply the latest stash; remove it on success.
git rm --cached <path> Stop tracking a file while keeping the local copy.
git reset --soft HEAD~1 Undo the latest commit while keeping its changes staged.
git restore --source=<commit> -- <path> Restore a working-tree path from a specific commit.
git stash apply Apply the latest stash without removing it.
git stash push -u Stash tracked changes and untracked files.

Examples

git stash push -m "work in progress" git stash list git stash pop
Save tracked-file changes, list and restore them.

Setup & repositories

Add untracked file patterns to .gitignore; it does not stop tracking files already committed.

Command Description
git clone <url> Create a local copy of a repository.
git init Initialize a repository in the current directory.
git remote add origin <url> Connect the repository to a remote named origin.
git config --global user.name "<name>" Set the default commit author name.
git config --global user.email "<email>" Set the default commit author email.

Examples

git init git add . git commit -m "Initial commit" git remote add origin <repo-url> git push -u origin HEAD
Create a repo and push to an empty remote.
