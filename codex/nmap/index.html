Nmap

Quick references for host discovery, port scanning, service detection and scan output.

Replace <…> with your value; […] is optional.

Usage: nmap [options] <target>. Options below attach to this command.

Targets & discovery

Command / option Description
nmap <target> Scan common TCP ports on an IP address or hostname.
nmap <network/CIDR> Scan targets in a network range.
-sn Discover hosts without scanning ports.
-Pn Skip discovery and treat every target as online.
-n Skip reverse DNS resolution.
-iL <file> Read targets from a file.
--exclude <target> Exclude a host or network.
--excludefile <file> Read excluded targets from a file.
-6 Use IPv6 targets.
-sL List targets without port scanning; DNS may be queried.
-PS<ports> Discover hosts using TCP SYN probes.
-PA<ports> Discover hosts using TCP ACK probes.
-PE Discover hosts using ICMP echo probes.

Examples

nmap -sn 192.168.1.0/24
Discover online hosts without a port scan.

Ports & scan types

Command / option Description
-sS TCP SYN scan; requires raw-packet privileges.
-sT TCP connect scan; works without raw-packet privileges.
-sU UDP scan; requires raw-packet privileges.
-p <ports> Scan selected ports, such as 22,80,443 or 1-1024.
-p- Scan ports 1–65535 for the selected protocol.
--top-ports <count> Scan the most frequently used ports.
-F Scan fewer ports than the default selection.
-p T:<ports>,U:<ports> Choose TCP and UDP ports; enable both scan types.
--exclude-ports <ports> Exclude ports from scanning and discovery.

Examples

nmap -sV -p 22,80,443 192.168.1.10
Identify services on three selected TCP ports.
sudo nmap -sS -sU -p T:22,80,443,U:53 192.0.2.10
Scan selected TCP ports and UDP DNS on a lab target.

Service & OS detection

Command / option Description
-sV Probe open ports to identify services and versions.
-A Enable -sV, -sC, -O and --traceroute.
-O Attempt OS detection; requires raw-packet privileges.
--version-light Use fewer service probes for faster identification.
--version-all Try all service-detection probes.
--traceroute Trace paths after supported raw-packet scans.

Examples

nmap -sV <target>
Identify services and versions on scanned ports.
nmap -sC -sV <target>
Run default scripts and identify service versions.

NSE scripts

Command / option Description
-sC Run the default set of NSE scripts.
--script <script> Select scripts by name, category or expression.
--script-args <args> Pass script arguments as key=value pairs.
--script-help <script> Read a script’s description and usage.
--script-timeout <time> Limit the runtime of each script instance.

Examples

nmap --script http-title -p 80 192.168.1.10
Read an HTTP page title on port 80.

Timing & performance

Command / option Description
-T<0-5> Set the timing template; 3 is the default.
--max-rate <rate> Limit the sending rate to packets per second.
--min-rate <rate> Request a minimum packet rate when possible.
--max-retries <count> Limit retransmissions of port-scan probes.
--host-timeout <time> Stop scanning a host after the specified duration.

Output & troubleshooting

Command / option Description
-oA <basename> Save normal, XML and grepable output together.
-oN <file> Save results in normal text format.
-oX <file> Save results as XML.
-v Increase output detail; repeat as -vv for more.
--open Only show open or potentially open ports.
--reason Show why a host or port received its state.
--resume <file> Resume using a normal or grepable output file.
--stats-every <time> Print periodic scan progress.
--packet-trace Print sent and received packet summaries.

Examples

nmap -sV -oA scan 192.168.1.10
Save normal, XML and grepable scan files.
