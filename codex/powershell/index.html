Codex/PowerShell

PowerShell

Everyday commands for files, object pipelines, processes and Windows administration.

Replace <…> with your value; […] is optional.

Pipelines pass objects. Pipeline commands follow <command> |; Windows-only cmdlets require Windows.

Files & navigation

Command Description
Get-ChildItem <path> List files and directories.
-Recurse Include child directories recursively.
-Filter <pattern> Filter names using the provider, such as *.log.
-Force Include hidden and system items when supported.
Set-Location <dir> Change the current location.
Get-Location Show the current location.
Test-Path <path> Check whether a path exists.
Get-Content <file> Read file contents.
-Raw Read the file as one string.
-Encoding utf8 Specify the text encoding.
Get-Content <file> -Tail <count> -Wait Follow appended lines in a text file.
Select-String -Path <file> -Pattern <regex> Find text matching a regular expression.
-SimpleMatch Treat the pattern as literal text.
-Context <before>,<after> Include surrounding lines.
-AllMatches Find all matches on each input line.
Copy-Item <source> <destination> Copy an item.
-Recurse Copy nested directories and their contents.
Move-Item <source> <destination> Move or rename an item.
New-Item <path> -ItemType File Create an empty file.
Remove-Item <path> Remove the selected item.
-Recurse Remove directory contents recursively.
-Force Include hidden or read-only items when permitted.
Set-Content <file> -Value <text> Write text, replacing existing file contents.
-Encoding utf8 Write using UTF-8 encoding.
Add-Content <file> -Value <text> Append text to a file.
-Encoding utf8 Append using UTF-8 encoding.
Get-FileHash <file> Calculate a file’s SHA-256 hash by default.
-Algorithm <name> Choose a hash algorithm; SHA256 is the default.

Examples

Get-ChildItem . -Filter *.log -Recurse
Find .log files in the current directory tree.

Pipelines & objects

Command Description
Where-Object { <condition> } Filter incoming objects.
Select-Object <properties> Choose output properties.
-First <N> Keep the first N objects.
Sort-Object <property> Sort incoming objects by a property.
-Descending Sort highest values first.
ForEach-Object { <action> } Process each incoming object.
Measure-Object Count incoming objects.
-Property <name> -Sum Sum the values of a numeric property.
<command> | Get-Member Inspect object properties and methods.
Format-Table [<properties>] Format objects as a table for display.
Format-List [<properties>] Format properties as a vertical list.
Out-File <file> -Encoding utf8 Write formatted output to a UTF-8 file.
Tee-Object -FilePath <file> Save output and pass it through the pipeline.

Examples

Get-Process | Where-Object { $_.CPU -gt 60 }
Select processes using over 60 CPU seconds.
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Show five processes with the highest CPU time.

Processes & services

Command Description
Get-Process List running processes.
Get-Process -Id <pid> Inspect a process by ID.
Get-Service [<name>] List Windows services or inspect one.
Stop-Process -Id <pid> Stop the selected process.
Restart-Service <name> Restart a Windows service.
Start-Service <name> Start a service.
Stop-Service <name> Stop a service.
Start-Process <program> Start a program or process.
Get-CimInstance <class> Query CIM management information.

Examples

Get-CimInstance Win32_OperatingSystem | Select-Object Caption, LastBootUpTime
Inspect the Windows edition and last boot time.

Logs & networking

Command Description
Get-WinEvent -LogName <log> Read events from a Windows log.
-MaxEvents <N> Return at most N events.
Get-WinEvent -FilterHashtable @{LogName='System'; Id=6005} Read System events with event ID 6005 on Windows.
Get-WinEvent -Path <file.evtx> Read events from a saved Windows event log.
Test-NetConnection <host> -Port <port> Test a TCP connection on Windows.
Test-Connection <host> Send ICMP echo requests.
Get-NetIPConfiguration Show IP addresses, gateways and DNS settings.
Get-NetIPAddress List configured IP addresses.
Get-NetAdapter List network adapters and link status.
Get-NetTCPConnection List TCP connections on Windows.
-State Listen Show listening TCP sockets.
Resolve-DnsName <domain> Resolve a DNS name.
Get-DnsClientCache List cached DNS records.
Clear-DnsClientCache Clear the DNS resolver cache.

Examples

Get-WinEvent -FilterHashtable @{LogName='System'; Level=2}
Read error-level System events on Windows.
Get-WinEvent -Path .\System.evtx -MaxEvents 20
Read the most recent 20 events from a saved log.

Windows network utilities

Command / option Description
ipconfig Show basic adapter IP configuration.
ipconfig /all Show full adapter, DHCP and DNS details.
ipconfig /displaydns Show cached DNS records.
ipconfig /flushdns Clear the DNS resolver cache.
ipconfig /release [<adapter>] Release a DHCP IPv4 lease.
ipconfig /renew [<adapter>] Renew a DHCP IPv4 lease.
arp -a Show the IPv4 ARP cache.
nslookup <domain> [<server>] Query DNS using an optional server.
tracert <host> Trace the route to a destination.
pathping <host> Trace a route and measure loss over time.
route print Show the Windows routing table.

Examples

nslookup example.com 1.1.1.1
Resolve a domain using a specified DNS server.

Data & requests

Command Description
Import-Csv <file> Read CSV rows as objects.
Export-Csv <file> -NoTypeInformation Save incoming objects as CSV.
ConvertFrom-Json Parse incoming JSON text into objects.
ConvertTo-Json Serialize incoming objects as JSON.
-Depth <N> Set nesting depth; the default is only 2.
Invoke-RestMethod -Uri <url> Request an endpoint and parse its response.
-Method <method> Set the HTTP method.
-Headers <hashtable> Add request headers.
-Body <data> Supply request data.
-ContentType <type> Set the request body content type.
Invoke-WebRequest -Uri <url> Request a web resource and inspect its response.
-OutFile <file> Save the response body to a file.

Examples

$rows = Get-Process | Select-Object Name, Id $rows | Export-Csv processes.csv -NoTypeInformation
Export process names and IDs to a CSV file.
Get-Content config.json -Raw | ConvertFrom-Json
Read a JSON file into PowerShell objects.
$data | ConvertTo-Json -Depth 10
Preserve nested data beyond the default JSON depth.

Help & scripting

Command Description
Get-Help <command> Show help for a command.
-Examples Show command examples.
-Full Show the full help topic.
Get-Command <pattern> Find available commands.
$name = <value> Assign a variable.
$env:<name> Read an environment variable.
<command> -LiteralPath <path> Treat a supported path literally, without wildcards.
<command> -ErrorAction Stop Turn non-terminating errors into terminating errors.
<command> -WhatIf Preview an action when the command supports it.
<command> -Confirm Request confirmation when supported.
Get-History List command history from the current session.
Get-Clipboard Read text from the clipboard.
Set-Clipboard -Value <text> Write text to the clipboard.

Examples

try { Get-Item -LiteralPath '.\missing.txt' -ErrorAction Stop } catch { Write-Warning $_.Exception.Message }
Catch a command error and show its message.
