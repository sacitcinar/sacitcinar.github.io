HTTP / cURL

HTTP methods, response codes and practical curl options for everyday requests.

Replace <…> with your value; […] is optional.

Options below follow curl <url>. In Windows PowerShell 5.1, use curl.exe to avoid the curl alias.

Examples use POSIX-shell quoting and illustrative example.com URLs.

Everyday requests

Command / option Description
curl <url> Request a URL and print the response body.
-I Make a HEAD request and show headers.
-i Include response headers with the body.
-L Follow HTTP redirects.
-H "<name>: <value>" Add or replace a request header.
-X <method> Set the method; does not supply a request body.

Request data & authentication

Command / option Description
-d '<data>' Send a request body; HTTP defaults to POST.
--json '<json>' Send JSON with JSON Content-Type and Accept.
-H 'Authorization: Bearer <token>' Send a bearer token header.
-u '<user>:<password>' Supply credentials for server authentication.
-F '<field>=@<file>' Upload a file as multipart form data.
--data-urlencode '<name>=<value>' Send a URL-encoded form field; defaults to POST.
-G --data-urlencode '<name>=<value>' Send URL-encoded data in the query string.
--data-binary @<file> Send the file body without text conversion.
-b '<name>=<value>' Send cookies; -b <file> reads a cookie file.
-c <file> Save received cookies to a cookie jar file.

Examples

curl --json '{"name":"demo"}' https://example.com/api
Send a JSON POST request.
curl -H 'Authorization: Bearer TOKEN' https://example.com/api
Send an example bearer token.
curl -F 'file=@report.pdf' https://example.com/upload
Upload a file as multipart form data.
curl -G --data-urlencode 'q=hello world' https://example.com/search
Add a URL-encoded query parameter.
curl -b 'session=DEMO' -c cookies.txt https://example.com
Send a cookie and save received cookies.

Files & output

Command / option Description
-o <file> Save the response body to a local file.
-O Use the filename from the URL path.
-sS Hide progress while retaining error messages.
-D <file> Save response headers to a file.
-w '%{http_code}' Print the HTTP status after the transfer.
-C - Resume a transfer from the local file size.
-T <file> Upload a file; HTTP defaults to PUT.

Examples

curl -L -o report.pdf https://example.com/report.pdf
Follow redirects and save the response body.
curl -C - -o archive.zip https://example.com/archive.zip
Resume a previously interrupted download.

Connections & troubleshooting

Command / option Description
-v Show verbose connection and header details.
--connect-timeout <seconds> Limit the connection establishment time.
--max-time <seconds> Limit the total transfer duration.
--fail-with-body Return an error for HTTP 400+ and keep the body.
--retry <N> Retry eligible transient failures up to N times.
--retry-delay <seconds> Set the delay between retry attempts.
-k Skip TLS certificate verification.
--cacert <file> Verify the server using a custom CA certificate file.
-x <proxy-url> Send requests through a proxy.
--resolve <host>:<port>:<ip> Override address resolution for a host and port.
--compressed Request compressed data and decompress the response.
-4 / -6 Resolve names to IPv4 / IPv6 addresses only.
--http1.1 / --http2 Request HTTP/1.1 / HTTP/2 when supported.

Examples

curl -v --connect-timeout 5 --max-time 20 https://example.com
Inspect the connection with time limits.
curl --resolve example.com:443:192.0.2.10 https://example.com/
Test a specific server while keeping the hostname and TLS name.

HTTP methods

Method Description
GET Retrieve a representation of a resource.
POST Submit data for resource-specific processing.
PUT Create or replace the target resource state.
PATCH Apply partial changes to a resource.
DELETE Request removal of the target association.
HEAD Retrieve GET-like headers without the body.
OPTIONS Request supported communication options.

Common response codes

2xx Success
200 OK — the request succeeded.
201 Created — one or more resources were created.
202 Accepted — processing has not necessarily completed.
204 No Content — success without a response body.
206 Partial Content — a range response.
3xx Redirection
301 Moved Permanently — use the new location.
302 Found — a temporary redirect.
303 See Other — follow the Location to retrieve a result.
304 Not Modified — reuse a cached representation.
307 Temporary Redirect — preserve the request method.
308 Permanent Redirect — preserve the request method.
4xx Client errors
400 Bad Request — the server cannot process the request.
401 Unauthorized — authentication credentials are needed.
403 Forbidden — the server refuses the request.
404 Not Found — the target resource was not found.
405 Method Not Allowed — method unsupported for this resource.
408 Request Timeout — request not received in time.
409 Conflict — request conflicts with resource state.
410 Gone — the resource is no longer available.
413 Content Too Large — request content exceeds a limit.
415 Unsupported Media Type — request format is unsupported.
416 Range Not Satisfiable — requested range cannot be served.
422 Unprocessable Content — content cannot be processed.
429 Too Many Requests — a rate limit was exceeded.
5xx Server errors
500 Internal Server Error — an unexpected server failure.
502 Bad Gateway — an invalid upstream response.
503 Service Unavailable — the server is temporarily unable.
504 Gateway Timeout — an upstream response was too late.
