Vim

Essential Vim keys for editing, movement, search, saving and working with multiple files.

Replace <…> with your value; […] is optional.

Keys apply in Normal mode unless stated. : starts a command; / between keys separates alternatives.

In examples, → separates successive keystrokes; do not type the arrows.

Modes & inserting

Key / command Description
Esc Return to Normal mode.
i Insert before the cursor.
I Insert before the first non-blank character.
a Insert after the cursor.
A Insert at the end of the line.
o Open a new line below and enter Insert mode.
O Open a new line above and enter Insert mode.
v Start characterwise Visual selection.
V Start linewise Visual selection.
Ctrl+v Start blockwise Visual selection.

Saving & quitting

Key / command Description
:w Save the current file.
:wq Save and close the current window.
:q Close the current window if no changes are pending.
:q! Close the window and discard unsaved changes.
:w <file> Write the buffer to the specified file.

Movement

Key / command Description
h / j / k / l Move left / down / up / right.
w / b Move to the next / previous word start.
e Move to the end of a word.
0 / $ Move to the start / end of the line.
^ Move to the first non-blank character.
gg / G Move to the first / last line.
<line>G Jump to a line number.
Ctrl+d / Ctrl+u Scroll down / up half a screen.
f<char> Find the next character on the current line.
% Jump to a matching bracket.
Ctrl+o / Ctrl+i Move backward / forward through the jump list.
<count><motion> Repeat a motion, such as 3w.

Editing & undo

Key / command Description
u Undo the last change.
Ctrl+r Redo an undone change.
dd Delete the current line into a register.
dw Delete through the next word start.
yy Copy the current line into a register.
p / P Put register contents after / before the cursor.
x Delete the character under the cursor.
ciw Replace the word under the cursor.
cw Change from the cursor to the word end.
D / C Delete / change from the cursor to the line end.
diw Delete the word under the cursor.
ci" Change the text inside double quotes.
r<char> Replace the character under the cursor.
. Repeat the last change.
>> / << Indent / unindent the current line.
J Join the current and next line.
<count><operator><motion> Repeat an edit, such as 3dw to delete three words.
"+yy / "+p Copy the current line to / paste from the system clipboard when supported.
q<register> … q Record a macro into a register.
@<register> Run a recorded macro.

Examples

V → j → >
Select this line and the next, then indent both.

Search & replace

Key / command Description
/<pattern> Search forward.
?<pattern> Search backward.
n / N Repeat the search / reverse its direction.
* Search forward for the word under the cursor.
:nohlsearch Clear the current search highlighting.
:%s/<old>/<new>/gc Replace matches throughout the file with confirmation.
:set number Show line numbers.
:set ignorecase Ignore case in searches.
:set smartcase With ignorecase, uppercase patterns become case-sensitive.

Examples

:%s/old/new/gc
Replace matches throughout the file, confirming each.

Files, windows & help

Key / command Description
:e <file> Open a file in the current window.
:ls List buffers.
:bn / :bp Switch to the next / previous buffer.
:split <file> Open a file in a horizontal split.
:vsplit <file> Open a file in a vertical split.
Ctrl+w w Move to the next window.
:help <topic> Open Vim help for a topic.
:bd Delete the current buffer; modified buffers require handling.
Ctrl+w h / j / k / l Move to the left / lower / upper / right window.
Ctrl+w = Make split windows equal in size.

Examples

:vsplit notes.txt → Enter → Ctrl+w w
Open a vertical split, then switch windows.
