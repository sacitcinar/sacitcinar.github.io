Files & directories

Command / option Description
ls [<dir>] List directory contents.
-l Long listing format
-a Include hidden entries
-h Human-readable sizes with -l
-t Newest modification time first
-R List subdirectories recursively
cd <dir> Change the working directory.
.. Move to the parent directory.
- Return to the previous working directory.
~ Move to your home directory.
pwd Print the current working directory.
cp <source> <destination> Copy files; directories require -r or -a.
-a Copy recursively and preserve file attributes
-r Copy directories recursively.
-i Ask before overwriting.
-n Do not overwrite existing destinations.
mv <source> <destination> Move or rename files and directories.
-i Ask before overwriting.
-n Do not overwrite existing destinations.
mkdir <dir> Create directories.
-p Create missing parent directories
rm <file> Remove files; use -r for directory contents.
-i Ask before removing a file
-r Remove directories and their contents recursively.
-f Ignore missing files and never prompt.
touch <file> Create an empty file or update its timestamps.
find <dir> Find files and directories.
-name "<pattern>" Match filenames against a pattern
-type f Match regular files
-iname "<pattern>" Match names without case sensitivity.
-type d Match directories.
-maxdepth <depth> Limit directory descent.
-mtime -<days> Match files modified within this many days.
-size +<N>M Match files larger than N MiB.
-user <user> Match files owned by a user.
-perm <mode> Match an exact permission mode.
-exec <command> {} \; Run a command once per matched path.
-print0 Print matched paths separated by NUL bytes.
du <dir> Show file and directory disk usage.
-s Show a total for each argument
-h Human-readable sizes
--max-depth=<depth> Limit reported directory depth.
df [<path>] Show filesystem space usage.
-h Human-readable sizes
tree [<dir>] Display a directory tree.
-a Include hidden files.
-L <depth> Limit the displayed directory depth.
-d Show directories only.
stat <file> Show file metadata.
ln -s <target> <link> Create a symbolic link.
which <command> Find an executable in the shell search path.
-a Show all matching executables in PATH.
locate <pattern> Find paths using the filename database.
-i Ignore case.
-e Only include paths that currently exist.
rmdir <dir> Remove an empty directory.
readlink -f <path> Resolve a path and its symbolic links.
realpath <path> Print the resolved absolute path.

Examples

find . -type f -name '*.log'
Find .log files beneath the current directory.
cp -r reports reports-backup
Copy a directory and its contents.

Text & editing

Command / option Description
cat <file> Print file contents.
less <file> Read text one page at a time.
q Quit the viewer
grep <pattern> <file> Find lines matching a pattern.
-i Ignore case
-n Show line numbers
-R Search directories recursively
-E Use extended regular expressions.
-F Match fixed strings.
-v Select nonmatching lines.
-w Match whole words.
-l List names of matching files.
-o Print only matched text.
-A <N> / -B <N> / -C <N> Show N lines after / before / around matches.
-q Return match status without printing output.
tail <file> Show the end of a file.
-f Follow newly appended lines
-n <count> Show the last N lines.
head <file> Show the beginning of a file.
-n <count> Print the first <count> lines
nano <file> Edit a file in the terminal.
sort <file> Sort lines of text.
-n Sort numerically.
-r Reverse the sort order.
-u Output unique lines.
-h Sort human-readable sizes.
uniq -c Count adjacent duplicate lines; sort first to group them.
wc <file> Count lines, words and bytes.
-l Count lines.
-w Count words.
-c Count bytes.
cut -f <fields> <file> Extract selected fields; tabs delimit by default.
-d <delimiter> Set the field delimiter
-f <fields> Select fields to extract
awk '<program>' <file> Process text by patterns and fields.
sed '<script>' <file> Filter and transform text.
tee <file> Write input to a file and standard output.
-a Append instead of replacing file contents.
jq <filter> <file> Query or transform JSON.
xargs <command> Build command arguments from standard input.
-0 Read NUL-separated input, such as find -print0.
diff <file1> <file2> Compare text files line by line.
file <path> Identify a file type.
strings <file> Extract printable strings from a file.
xxd <file> Display a hexadecimal dump.
-r Convert a hexadecimal dump back to bytes.
base64 <file> Encode a file as Base64.
-d Decode Base64 input.
sha256sum <file> Calculate a SHA-256 checksum.
tr '<set1>' '<set2>' Translate characters from standard input.
-d <set> Delete characters from the specified set.
-s <set> Squeeze repeated characters from the set.
column [<file>] Format input into columns.
-t Create a table from input fields.
-s <separator> Set the input field separator.

Examples

grep -n 'error' app.log
Find error lines and show their line numbers.
cut -d ':' -f 1 /etc/passwd
Print account names from the first field.
awk '{print $1}' access.log
Print the first whitespace-separated field.
sed 's/old/new/g' notes.txt
Print replaced text; leave the file unchanged.
find . -type f -name '*.log' -print0 | xargs -0 grep -n 'error'
Search matching files, including paths containing spaces.

Permissions & accounts

Command / option Description
sudo <command> Run commands with permitted privileges.
-l List permitted commands
-u <user> Run a command as the specified user.
whoami Print the effective username.
id Show user and group IDs.
chmod <mode> <file> Change file permissions.
640 Owner read/write; group read; others no access
+x Add execute permission
-R Change permissions recursively.
chown <user>:<group> <file> Change file ownership.
-R Change ownership recursively.
passwd [<user>] Change an account password.
usermod <options> <user> Modify an existing user account.
-aG <group> Append the user to a supplementary group.
-L Lock the account password.
useradd <user> Create a user account.
-m Create the home directory.
-s <shell> Set the login shell.
userdel <user> Delete a user account.
-r Also remove the home directory and mail spool.
getent <database> Query configured account databases.
last Show login history.
-a Show the hostname in the last column
addgroup <group> Create a group on Debian-based systems.
delgroup <group> Delete a group on Debian-based systems.

Examples

chmod 640 report.txt
Owner: read/write; group: read; others: none.

System & terminal

Command / option Description
uname Show kernel and system information.
-a Show all available system information
hostname [<name>] Show or set the system hostname.
uptime Show system uptime and load averages.
free Show memory usage.
-h Human-readable sizes
lsblk List block devices.
-f Show filesystem information
date Show the current date and time.
-u Use UTC.
clear Clear the terminal display.
cal [<month> <year>] Display a calendar.
man <command> Open a command’s manual page.
<command> --help Show help for commands that support --help.

Shell & redirection

Command / option Description
<cmd1> | <cmd2> Pipe standard output into another command.
<command> > <file> Write standard output, replacing the file.
<command> >> <file> Append standard output to a file.
<command> < <file> Read standard input from a file.
<command> 2> <file> Write standard error to a file.
<command> > <file> 2>&1 Write standard output and error to the same file.
<cmd1> && <cmd2> Run the second command only if the first succeeds.
<cmd1> || <cmd2> Run the second command only if the first fails.
echo "<text>" Print a line of text.
printf '%s\n' "<text>" Print text using an explicit format.
history List shell command history.
printenv [<name>] Print environment variables.
env Print the environment or run a command with modified variables.
export <name>="<value>" Set a variable for this shell and child processes.
source <file> Run a file in the current shell.
Ctrl+R Search command history interactively.
Ctrl+C Send an interrupt to the foreground process group.
Ctrl+Z Suspend the foreground job.
<command> & Start a job in the background.
jobs List jobs in the current shell.
fg [%<job>] Bring a job to the foreground.
bg [%<job>] Resume a suspended job in the background.

Examples

grep -i error app.log > errors.txt 2>&1
Search a log and save output and errors together.

Processes & services

Command / option Description
ps Show running processes.
aux List processes for all users, including those without a terminal
-ef Show all processes in full format.
systemctl <action> <service> Inspect and manage systemd services.
status Show service state and recent log entries.
start Start the service now.
stop Stop the service now.
restart Stop and start the service.
reload Reload service configuration when supported.
enable Enable startup at boot; does not start it now.
disable Disable automatic startup.
is-active Check whether a service is active.
journalctl Read systemd journal entries.
-u <service> Filter by service
-f Follow new journal entries.
--since <time> Filter by start time
--since today Show today’s entries
-b Show the current boot
-k Show kernel messages.
-p <priority> Filter by message priority
top Monitor processes and resource usage.
htop Interactively monitor processes and resource use.
kill <pid> Send a signal to a process.
-TERM Request graceful termination
-KILL Force termination when graceful stopping fails.
pgrep <pattern> Find processes by name or command line.
-a Show the full command line
-f Match the full command line
pkill <pattern> Signal processes matching a name pattern.
lsof <path> List processes with a path open.
-i :<port> List network sockets using a port.
watch -n <seconds> <command> Repeat a command and refresh its output.
timeout <duration> <command> Stop a command after the specified duration.

Examples

journalctl -u ssh --since today
Read today’s entries for the ssh service.
watch -n 2 'ss -tuln'
Refresh listening TCP and UDP sockets every two seconds.

Networking & remote access

Command / option Description
ip <object> [<action>] Show and manage network interfaces and routes.
-br addr Show interface addresses briefly
route Show the routing table
link Show network interfaces and link state.
neigh Show neighbor and ARP entries.
ping <ip> Test network reachability with ICMP.
-c <count> Send <count> echo requests
ss Inspect network sockets.
-t TCP sockets
-u UDP sockets
-l Listening sockets
-n Numeric addresses and ports
-p Show associated processes when permitted.
ssh <user>@<host> Open an encrypted remote shell.
-p <port> Connect to the specified port.
-i <keyfile> Use the specified private key.
curl <url> Transfer data and inspect HTTP responses.
-I Make a HEAD request and show headers.
dig <domain> Query DNS records.
+short Print a short answer.
@<server> Query a specified DNS server.
-x <ip> Perform a reverse DNS lookup.
wget <url> Download a file from a URL.
-O <file> Save output using the specified filename.
-c Resume a partial download.
tcpdump [<filter>] Inspect network traffic on authorized interfaces.
-i <interface> Select a capture interface
-nn Disable host and port name resolution
port <port> Filter traffic by port
-c <count> Stop after capturing N packets.
-w <file.pcap> Write packets to a capture file.
-r <file.pcap> Read packets from a capture file.
scp <source> <user>@<host>:<path> Copy a file over SSH.
-r Copy directories recursively.
-P <port> Use a nondefault SSH port.
rsync -av <source> <destination> Synchronize files while preserving common attributes.
--dry-run Preview changes without transferring files.
ifconfig [<interface>] Legacy interface tool; prefer ip on modern Linux.
-a Show all interfaces, including inactive ones.
netstat Legacy socket tool; prefer ss on modern Linux.
-t Show TCP sockets.
-u Show UDP sockets.
-l Show listening sockets.
-n Show numeric addresses and ports.
-p Show associated processes when permitted.

Examples

ss -tuln
List listening TCP and UDP sockets numerically.

Archives & compression

Command / option Description
tar <options> Create or extract tar archives.
-c Create an archive.
-x Extract an archive.
-t List archive contents.
-f <archive> Select the archive filename.
-z Use gzip compression.
-C <dir> Change directory before processing files.
gzip <file> Compress a file using gzip.
-d Decompress the file.
-k Keep the input file.
zip <archive.zip> <file> Create or update a ZIP archive.
-r <dir> Include a directory recursively.
unzip <archive.zip> Extract a ZIP archive.
-l List archive contents.
-d <dir> Extract into the specified directory.

Examples

tar -czf <archive.tar.gz> <dir>
Create a gzip-compressed archive.
tar -xzf <archive.tar.gz>
Extract a gzip-compressed archive.

Package management

Command / option Description
apt <action> Manage packages on Debian and Ubuntu.
update Refresh package indexes
upgrade Upgrade installed packages without removing packages.
list --upgradable List packages with updates available
install <package> Install a package.
remove <package> Remove a package; retain its configuration files.
dpkg -l List installed packages and package status.
dnf <action> Manage packages on Fedora and RHEL-based systems.
check-update Check for available package updates
install <package> Install a package.
remove <package> Remove a package.
pacman <options> Manage packages on Arch-based systems.
-Syu Refresh package databases and upgrade the system
-S <package> Install a package from configured repositories.
-R <package> Remove a package.

Examples

sudo apt install curl
Install curl on Debian or Ubuntu.
sudo apt update sudo apt upgrade
Refresh package lists, then upgrade packages.
