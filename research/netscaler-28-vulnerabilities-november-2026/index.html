Citrix NetScaler: 28 Vulnerabilities Patched in ADC and Gateway

Citrix released updates for 28 vulnerabilities in NetScaler ADC and Gateway, including nine critical flaws. The report covers configuration-dependent exposure, fixed builds and upgrade priorities.

A patch across NetScaler services

Cloud Software Group released fixes on 12 November 2026 for 28 vulnerabilities in customer-managed NetScaler ADC and Gateway. The update fixes 9 critical, 15 high and 4 medium-severity vulnerabilities.

NetScaler handles application delivery and remote access. Its exposure depends on the services each appliance processes, from load balancing to authentication and VPN traffic.

Citrix describes unpredictable behaviour and denial of service. High CVSS impact scores do not, by themselves, establish a working remote-code-execution exploit.

Several findings came from AI-assisted code analysis. Citrix also credits external researchers in the bulletin.

Two reasons to prioritise patching

CVE-2026-120868 / Packet processing / CVSS v4.0 9.3

A buffer-bounds failure in core packet processing affects ADC and Gateway without requiring an additional feature, including the default configuration. The CVSS vector specifies network access, no privileges and no user interaction.

An appliance that does not use DNS load balancing, SMPP or a particular authentication method still meets this vulnerability’s configuration condition.

CVE-2026-107412 / Gateway and AAA / CVSS v4.0 9.5

This CVE groups multiple memory overflows. It applies to Gateway configurations using SSL VPN, ICA Proxy, clientless VPN or RDP Proxy, and to authentication, authorisation and accounting (AAA) virtual servers.

The vector specifies no authentication or user interaction, with an additional attack requirement (AT:P). The public advisory does not explain that requirement or provide a complete exploit mechanism.

Prioritise internet-facing Gateway and AAA appliances. Other affected ADC deployments still require the update because the packet-processing flaw has no additional feature prerequisite.

A distinct data-exposure issue

CVE-2026-111338 writes sensitive authentication material to /var/log/httperror.log. Exploitation requires local read access after a logout has occurred.

Customer-managed deployments

The bulletin applies to appliances managed by customers. Secure Private Access Hybrid deployments using NetScaler instances must also update those instances.

Citrix-managed services

Citrix says the covered Secure Private Access, Gateway Service, Adaptive Auth and NetScaler Console Service environments have already received the security updates.

Plan the upgrade and verify completion

Order and service impact

Citrix specifies upgrading ADC/Gateway before NetScaler Console. Existing ICA sessions terminate during the upgrade and must be started again afterwards.

For environments using pooled or flexed Console-based licensing, moving from a pre-14.1-51.x Console build may require a LAS exception or extension. Review the vendor’s licensing sequence before scheduling the change.

Check the upgrade result

NetScaler Console can list affected instances in CVE Detection and initiate an upgrade workflow. Its assessment may take several hours to refresh; the documentation provides a Scan-Now option.

After the upgrade, confirm the intended build and check the application-delivery and remote-access functions used by the deployment.

Exploitation status at disclosure

At publication, Citrix reported no known unmitigated exploits for the announced vulnerabilities. CERT-EU reported no confirmed public proof of concept. This describes the disclosure status on 12 November 2026.
